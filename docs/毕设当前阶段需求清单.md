# 七、竞赛负责人设计（新增）

## 1. 设计目标

- 将竞赛相关审核职责从管理员中拆分
- 提升权限划分合理性
- 更贴近真实竞赛管理流程

## 2. 角色定位（推荐方案）

- 基础角色仍为：
  - 管理员 / 教师 / 学生
- 竞赛负责人：
  - 从教师中指定
  - 属于扩展权限

## 3. 核心功能

- 查看负责的竞赛
- 审核创建队伍申请
- 查看队伍列表与成员

## 4. 权限限制

- 不管理用户
- 不审核教师注册
- 不管理全部竞赛

## 5. 关键规则

- 不可申请自己负责的竞赛
- 可参与其他竞赛

## 6. 数据库最小改动

- competitions 表增加 manager_id

## 7. 页面设计

- 教师端新增“我负责的竞赛”

## 8. 实现策略

- 先完成基础功能
- 再扩展负责人机制
